# AI and Tool Disclosure

This project was developed using standard software libraries, document-processing tools, and AI-assisted development support.

## Software and Libraries Used

- **Python 3.10** — main development language
- **Streamlit** — interactive clinical prototype interface
- **SentenceTransformers** — semantic embedding generation
- **all-MiniLM-L6-v2** — pretrained embedding model
- **FAISS** — vector indexing and semantic retrieval
- **NumPy / JSON utilities** — data handling and storage
- **VS Code** — development environment
- **diagrams.net (draw.io)** — final system architecture diagram
- **Microsoft PowerPoint** — presentation preparation

## AI Assistance

ChatGPT was used as a development and writing assistant for tasks including:

- debugging Python and Streamlit code;
- improving code organization and user-interface presentation;
- discussing the canonical-card structure;
- refining the applicability-aware retrieval design;
- drafting documentation and presentation wording;
- organizing evaluation outputs and comparison reporting;
- assisting with architecture explanation and slide structure.

The clinical protocol content, recommendation cards, evaluation cases, experimental setup, final system behaviour, source-page references, and reported results were reviewed and retained within the project files rather than being accepted solely from AI-generated text.

## Scope of AI Use

AI assistance was used to support implementation, debugging, organization, and communication. It was not treated as an independent clinical validator. The reported evaluation consists of predefined safety-and-behaviour checks on six fictional cases and should not be interpreted as clinical accuracy or real-world clinical validation.

## External Model Use

The prototype uses the pretrained `all-MiniLM-L6-v2` sentence-transformer model for semantic embeddings. No custom model training, fine-tuning, or clinical model training was performed as part of this assessment.
